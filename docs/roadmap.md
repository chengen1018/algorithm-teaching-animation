# Roadmap

[返回 README](../README.md)

Roadmap 只列出目前維護者願意評估與 review 的方向，不代表交付承諾，也不設定虛構日期。

## 近期方向

- 改善 macOS、Linux 與 Windows 的安裝說明與環境檢查。
- 增加 Skill、references 與 scripts 之間的 contract test coverage。
- 補充更多已驗證的演算法動畫設計模式。
- 簡化新使用者第一次設定 Manim、字型與 Kokoro 的流程。

## 後續評估

- 評估可替換的本機 TTS 選項，同時保留旁白驗證契約。
- 評估不需要完整 render 的整合測試範圍。
- 根據真實使用回報改善 layout audit 與 delivery verification 的錯誤訊息。

具體提案請先建立 [Feature Request](https://github.com/chengen1018/manim-algorithm-animation-maker/issues/new?template=feature_request.yml)，說明問題、範圍與驗收條件。

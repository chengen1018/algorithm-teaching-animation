# Manim Algorithm Animation Maker v0.1.0

第一個公開版本，提供完整的 Codex Skill、五階段動畫製作流程、本機驗證工具、繁體中文使用文件與三支實際產生的演算法教學影片。

## 主要內容

- 四幕 Manim 演算法教學動畫 contract。
- 動畫設計、腳本、旁白、Scene 實作、版面檢查、正式渲染與交付驗證流程。
- 八種 subagent roles 與明確委派規則。
- Kokoro TTS 本機旁白支援。
- 快速 Repository checks。
- MIT License 與完整 community health files。

## 安裝需求

- Codex 與可用的 subagent 功能。
- Manim 與可執行它的 Python 環境。
- FFmpeg／FFprobe 與支援目標語言的字型。
- 依 [Kokoro 設置文件](https://github.com/chengen1018/manim-algorithm-animation-maker/blob/v0.1.0/KOKORO_SETUP.md)準備的本機 TTS environment。

完整安裝方式請參考 [README](https://github.com/chengen1018/manim-algorithm-animation-maker/tree/v0.1.0#readme)。

## 已知限制

- 快速 CI 不會下載 TTS 模型，也不會執行正式 Manim render。
- 目前主要在 macOS 開發；Windows 與 Linux 的完整動畫流程尚未宣稱完成驗證。
- 動畫流程需要使用者明確同意使用 subagent。

## 升級說明

這是第一個公開版本，沒有前一個正式版本需要遷移。後續版本若改變 Skill contract、必要輸入或輸出，會在 Changelog 與 Release notes 中說明。
